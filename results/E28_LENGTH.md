# E28 — перенос на длины4/5 без дообучения

2026-09-08. Научная оценка завершена,0trainingupdates. **L4 PASS для W4 и float во всех3seeds; L5 FAIL для обоих по all-seeds критерию**. Независимое итоговое ревью **ACCEPT** подтвердило результат.

## Что проверили

Frozen E27 W4/A32 и E24 float u16000, seeds0/1/2. Ровно8 внутренних шагов PER instruction:32/40 шагов на программу длины4/5. Модель переносит непрерывное состояние между инструкциями; правильные промежуточные ответы ей не подставляются. Квантизаторы, веса и режим вычисления не изменялись.

Шесть программ каждой длины выбраны до новых forwards по deterministic SHA256 rank среди функций, не эквивалентных НИ ОДНОЙ более короткой программе на полном256-state домене. Исключались даже более короткие не обучавшиеся программы. Среди L4 найдено37 подходящих semanticclasses, L5 —86; оценены только заранее выбранные6изкаждой. Полный root selection/targets в `results/E28_SELECTION.json`; правила в [протоколе](E28_LENGTH_PROTOCOL.md).

Primary: finaljoint>=244/256 для каждой выбранной программы; conjunction отдельно по длине/model/seed и затем allseeds/all12programs. Secondary fulltrace>=244 отдельно, не подмена primary. Прежние seen prerequisites импортированы из accepted E24/E27, заново здесь не оценивались.

## Вывод и ограничения

Подтверждаем перенос на выбранные шесть минимально-L4 функций в трёх инициализациях для обеих моделей; устойчивый перенос на выбранные L5 функции не подтверждён. Результат не устанавливает универсальный предел «четыре инструкции»: оценены12functions, а не весь класс программ или все дальнейшие длины.

Одновременно меняются длина и содержание новых функций/композиций; это не изолированное причинное вмешательство только в длину. Возможны новые короткие фрагменты внутри длинных программ. Символическая новизна функции на256states не означает новизну каждой отдельной пары input/output. Программы выбраны без model predictions, но вся задача проводится после адаптивного выбора архитектуры/бюджета на прежнем открытом E21; нет общей reasoning гарантии или аппаратных измерений.

Следующий узкий вопрос — что отличает L5 случаи с поздним расхождением. Анализ уже сохранённых трасс возможен без обучения; новый протокол/запуск в E28 не назначается. Не добавлять циклы или дообучение автоматически.
