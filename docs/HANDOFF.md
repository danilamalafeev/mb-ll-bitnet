## Что реализовано

Основной код: `looped_bitnet/model.py`, `data.py`, `engine.py`, `quantization.py`.

- Controlled cycle из 16 объектов, перемешанные строки source→destination. Train/validation/test разделены по канонической таблице.
- Вход: таблица, стартовый объект, число переходов. Число переходов кодируется через подсчёт STEP; оно не управляет числом вычислительных витков автоматически.
- Один изменяемый вектор `h`; фиксированные K/V создаются один раз. Shared reader с query LayerNorm; четыре независимых pre-norm FFN посещаются A→B→C→D→A…
- На витке: `u=h+Reader(h,KV)`, затем `h_next=u+FFN_delta_i(u)`. Все обучаемые веса получают градиент через развёртку; состояния не заменяются правильными ответами.
- Пилот: d=64, FFN=256, 4 головы, обычно 8 витков, 152512 параметров. Тернарный QAT и INT8 fake-quant активаций симулируются FP32-операциями; packed inference kernels отсутствуют.
- `structured_reader=False` — исходная смешанная память. При `True`: существующий shared memory_norm отдельно на source/destination, затем прежние K/V-проекции. Параметры и ключи state_dict сохраняются.
- `persistent_query=False` по умолчанию. При True адаптер `[h,h0]` добавляет 8192 параметра. Убедительного эффекта не было.
- `forward_with_readouts()` возвращает дополнительные предсказания общим output head; обычный forward сохранён.
- Router, block-specific query, latent-записи, halting, свёртки и языковой decoder не реализованы.

## Теория и идеи

[RESEARCH_IDEAS.md](RESEARCH_IDEAS.md) — ограниченный разбор Loop Think & Generalize v2, Thinking Deeper Not Longer v1, FRM v3. Это записанные идеи, не обязательный план и не окончательно проверенные рекомендации. Простое detach между витками не воспроизводит FRM FPF; наш h уже обучается на собственных состояниях. Успешное декодирование b не доказывает его причинное использование. Большая норма FFN не означает «мусор» или процент информации.

Идея пользователя: блок с собственной state-dependent query-проекцией `Q_i=W_Q_i(h)` и общей KV-памятью, затем собственный FFN. Это отличается от постоянного обучаемого query-вектора; идея записана в EXPERIMENTS.md и пока не реализована.
